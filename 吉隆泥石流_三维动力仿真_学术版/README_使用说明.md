# 吉隆口岸冰岩崩—泥石流三维动力学仿真系统

本项目包含二维深度平均动力学求解、Voellmy摩擦阻力、侵蚀沉积模型、真实DEM、Streamlit交互程序、独立离线三维动画、计算过程图表及数值结果。网页采用研究型可视化排版，仅保留**冰崩点**与**吉隆口岸**两个位置标签。引用依据、模型条件及误差讨论放在本文件和《模型计算过程与数学说明.md》中。

## 1. 最快捷的查看方式

解压ZIP后，**保持目录结构完整**，双击 `index.html`，可离线访问：

- 三维地形与泥石流运动过程；
- 播放、暂停、上一帧、下一帧、时间滑块；
- 拖动旋转、滚轮缩放、俯视及复位视角；
- 数值计算过程曲线和CSV；
- 六张中文图、GeoTIFF输出。

若浏览器限制本地iframe，直接打开 `results/三维运动动画_离线网页.html` 和 `results/计算过程曲线_离线网页.html`。

**三维场景需要浏览器WebGL支持。** 建议Chrome或Edge，开启硬件加速。离线HTML含Plotly运行代码，浏览时无需联网。

## 2. Windows / PyCharm运行Streamlit

例：解压后目录为 `D:\bigdadta\吉隆泥石流_三维动力仿真_学术版`，而虚拟环境位于 `D:\bigdadta\.venv`。

在PyCharm下方的 **Terminal** 中执行：

```powershell
cd "D:\bigdadta\吉隆泥石流_三维动力仿真_学术版"
& "D:\bigdadta\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& "D:\bigdadta\.venv\Scripts\python.exe" -m streamlit run app.py
```

浏览器打开 `http://localhost:8501`。不要直接在PyCharm用绿色三角以 `python app.py` 方式执行网页程序。

你也可以双击 `一键启动交互网页.bat`，它会优先尝试使用项目所在目录或上一级目录的 `.venv`。

交互界面可以更改体积、阻力参数、侵蚀系数、时间和网格后重新计算。默认载入压缩包中已经算好的基准仿真，首次打开无需重新运算。

## 3. 命令行重算与导出

在项目根目录执行：

```powershell
python run_batch.py
```

如需指定计算条件：

```powershell
python run_batch.py --grid 90 --duration 600 --snapshot 10 --volume 175000000 --mu 0.06 --late-mu 0.01 --xi 5000 --erosion-k 0.000678
```

完成后会更新 `results` 和 `index.html`。不同试验请用 `--output` 保存到新目录，避免覆盖基准成果。

条件拟合的研究记录可以通过 `python run_literature_inversion.py --mode full --grid-check` 重新运行。该脚本是学术分析工具，不是展示网页的必需步骤。

## 5. 已计算的基准结果

计算设置：初始体积1.75亿m³；90米数值网格；600秒时长，保存间隔10秒；Voellmy初期摩擦系数0.06、后期0.01，阻力参数5000m/s²；侵蚀系数0.000678。

| 指标 | 结果 |
|---|---:|
| 首次进入口岸300米邻域 | 440 s |
| 全计算域累计侵蚀 | 58,520,359.82 m³ |
| 全计算域历史峰值速度 | 86.99 m/s |
| 最大直线扩展距离 | 21.11 km |
| 累计影响面积 | 31.56 km² |
| 初始释放区面积 | 4.026 km² |
| 初始格网平均厚度 | 43.47 m |
| 最终流动层体积 | 230,182,385.24 m³ |
| 最终累计沉积体积 | 3,337,974.07 m³ |

“进入口岸300米邻域”是依据流深阈值在保存时刻进行的空间判定，并非流速监测断面穿越时刻；最大直线扩展距离不是沿曲折河谷传播长度。

## 6. 动画交互与视角保持

新版将DEM地形和两处位置标记固定在一个Plotly WebGL场景中，只对**泥石流表面图层**调用 `Plotly.restyle` 更新栅格高程与流深颜色。它不再每帧执行三维场景重建。

- `scene.uirevision` 固定，用于持久化用户旋转与缩放状态；
- 播放期间鼠标按下拖动时暂缓更新流动层，释放鼠标后继续播放；
- 独立的时间轴、播放速度和俯视按钮；
- 可选显示密度与计算网格互相独立。

WebGL需要实际GPU或软件WebGL支持；本项目已经测试浏览器播放、按钮和时间滑块脚本，但受执行容器WebGL限制，未完成带GPU三维交互画面的端到端验证。

## 7. 模型依据与误差说明

本模型的控制方程为二维深度平均守恒方程，阻力为Voellmy库仑+速度相关阻力，并引入速度阈值侵蚀和低速沉积模型。**μ、ξ、k为指定模型、网格、物源设定和参考指标下的条件拟合候选值，不是现场直接测得的材料常数。**

当前初始物源基准采用刘昌军等的约1.75亿m³体积和约400万m²面积。源区坐标采用殷跃平等滑震初步定位参考点，实际源区边界仍由代码中的超椭圆近似。模型中的沉积参数、侵蚀阈值、可侵蚀层厚及阻力转换时间仍需敏感性分析。

当前90米网格下约440秒进入口岸邻域、累计侵蚀约5852万m³；相同参数改为60米网格时此前试算约400秒进入、侵蚀约6535万m³，说明数值网格敏感性明显。**前述5852万m³是整个计算裁剪区的侵蚀量，殷跃平等论文5860万m³为特定两河段侵蚀量，不能视为严格相同观测区域。**

参考：

- 殷跃平等，2026，《尼泊尔蓝塘里壤峰“8·26”冰岩崩致吉隆泥石流灾难研究》，DOI：10.16031/j.cghc.202610008。
- 刘昌军等，2026，《西藏吉隆“8·26”冰岩崩泥石流灾害链数字孪生推演分析》，DOI：10.3724/j.slxb.20260653。
- 杨云鹏等，2026，《基于地震动监测的“8·26”西藏吉隆泥石流灾害链初步解析》，DOI：10.16089/j.cnki.1008-2786.000980。

以上文献约束和不确定性仅写在学术说明文件中，不在可视化页面重复显示。
