# 第四问数值仿真结果简报

## 1. 模型与计算设置

采用二维深度平均质量与动量守恒模型，包含Voellmy摩擦阻力、速度阈值侵蚀与低速沉积项。真实DEM原始分辨率30米，数值计算网格90米；初始物源体积1.75亿立方米、释放区面积约402.58万平方米，平均厚度43.47米；仿真600秒、输出间隔10秒。

阻力及侵蚀候选参数：$\mu_0=0.060,\mu_1=0.010,\xi=5000\ \mathrm{m/s^2},k=0.000678$。该组值来自给定模型条件下的参数试算，不能将其解释为直接实测的物理常数。

## 2. 主要结果

| 统计项 | 计算结果 |
|---|---:|
| 首次进入口岸300米邻域 | 440 s |
| 累计最大直线扩展距离 | 21.106 km |
| 全域瞬时峰值速度 | 86.990 m/s |
| 累计影响面积 | 31.560 km² |
| 累计侵蚀体积 | 58,520,359.82 m³ |
| 累计沉积体积 | 3,337,974.07 m³ |
| 末时刻流动层体积 | 230,182,385.24 m³ |
| 末时刻口岸最近有效像元距离 | 45.32 m |
| 最终相对质量收支残差 | -2.97×10⁻⁹ |

### 结果解释

模拟显示源区物质经DEM地形驱动沿低高程沟谷运动，侵蚀夹带导致流动层总体积增加。流动层最先进入口岸300米邻域的保存时刻为440秒。这是模型在给定源区与网格下的空间阈值统计值，不等同于精确断面到达时间。侵蚀量统计范围为全部模型计算域，与殷跃平等论文两河段侵蚀量并非完全对应。

## 3. 模型质量检验

- 初始体积精确初始化，通过释放体积测试。
- 无侵蚀情况下的质量守恒通过数值测试。
- 静水平衡通过边界测试。
- 侵蚀与沉积物质收支通过单元测试。
- 与此前60米网格试算相比，到达时间和侵蚀量变化较明显，仍需进一步进行网格收敛分析。
