# 第四问二维动力学、数值求解与三维展示：过程说明

## 1. 输入数据

30m EPSG:32645 DEM，源区参考坐标 `(357868.39,3135259.01)`；口岸 `(340897.90,3129236.91)`；灾害位置 `(340873.07,3129127.39)`。均可从随项目附带的坐标审计文件追踪。DEM计算窗口包围源区至口岸并增加外侧边距，基准网格为约90m。边界封闭，`edge_wet_cells`报告是否发生触边。

## 2. 初始物源几何

按不同论文配对体积与面积，不互换不相容的几何：刘昌军等2026年DoD约1.75亿m³、约400万m²、平均约45m；模型用2040×2040m、p=6超椭圆近似，离散面积约4.026km²、初始流深43.47m；殷跃平等2026年源区约1000×600m、约1.1亿m³，用对应尺寸的近似。公式：`h0=V0/(释放掩膜格网数×dx×dy)`。释放掩膜为假设轮廓，不是实际卫星勾绘边界。

## 3. 质量和动量方程

令 `U=(h,hu,hv)^T`，`z(x,y)`为地面标高，`u,v`为深度平均速度，`g=9.81m/s²`：

```
∂h/∂t + ∂(hu)/∂x + ∂(hv)/∂y = E-D
∂(hu)/∂t + ∂(hu²+0.5gh²)/∂x + ∂(huv)/∂y = -gh ∂z/∂x + Sfx + Mx
∂(hv)/∂t + ∂(huv)/∂x + ∂(hv²+0.5gh²)/∂y = -gh ∂z/∂y + Sfy + My
```

数值离散：Rusanov局部Lax–Friedrichs通量；hydrostatic reconstruction保证静水体初始平衡；基于CFL自适应时间步长；程序对负流深作检查，动量在干湿界面显式处理。体积增减项来自下方的经验侵蚀与沉积；没有冰岩崩3D碰撞、二相冰水相变等过程。

## 4. Voellmy摩擦与流态化假设

当 `s=sqrt(u²+v²)`，参考代码 `q4_solver.py::_friction` 中的速度损失为：

```
Δs/Δt = -( μ g cosθ + g s²/(ξ max(h,0.2)) )
```

方向取运动速度反向，数值更新不允许速度反号。`μ`无量纲，`ξ`在本项目中为m/s²。程序初期`μ=0.20`、100秒后人为切换到`μ=0.05`，`ξ=1800m/s²`。该切换用于探索流态化效应，不意味着真实阻力在恰好100秒发生骤变。未来应按河段、物性、视频测速进行标定。

## 5. 侵蚀沉积源项

代码使用经验式（不是文献直接测量的侵蚀定律）：

```
E = k × max(s-15,0) × min(1,h/2)   [m/s]
D = kdep × h                      [m/s]，仅当s<5m/s
```

其中`k=0.003`、`kdep=0.0003s⁻¹`是假设，侵蚀受25m床层上限限制。E使流动层厚度增加且床面z降低，侵入物质初始动量按零处理；D则使h下降、z升高并移除相应流动动量。程序假设密度不变，不含河水汇入、碰撞冲蚀、河道断面形态恢复等额外机制。不能把论文的侵蚀体积直接代入唯一求出k，必须先统一侵蚀公式及河段覆盖范围。

## 6. 逐时刻数值记录和守恒

每20秒保存一次：`运动层体积、累计侵蚀体积、累计沉积体积、质量收支误差、覆盖面积、最远直线扩展距离、当前速度峰值、历史速度峰值、最接近口岸的距离、质心UTM坐标`，输出`results/模拟过程时序.csv`。守恒相对误差：

```
ε = (Vflow(t) + Vdeposit(t) - Verosion(t) - Vinitial) / Vinitial
```

仅代表该简化模型的**体积数值守恒**，不能代表对真实灾害的正确性验证。

## 7. 三维时间动画

`q4_viz.plotly_scene`读取真实米制格网x/y、DEM绝对海拔z，在DEM上叠加每一时刻的h值（使用3D散点图、颜色对应流深；视觉上浮10m便于辨识），添加滑震源区、口岸、灾害点。Plotly提供时间滑块、播放、暂停、旋转和缩放。

## 8. 量纲与对照口径

- 图中最大直线传播距离为所有到达网格距反演源区点的最大欧氏距离，不是文献的约23公里弯曲河谷路径。
- 图中全域历史最大网格速度不是文献的前缘传播速度或口岸局部流速。
- 此次输出未到达口岸300m区域，不应填报模拟到达时间、模拟口岸流速。
- 刘昌军等的全程侵蚀2.60亿m³、殷跃平等的两河段5860万m³，空间范围不同，也不与本模型全裁剪域的侵蚀量具有直接一致性。
- 杨云鹏等初始130s、下游320s阶段数据能用于**以后**设置有地理坐标的交汇口断面反演，但附件没有提供交汇口精确点位，程序没有人为编造这个点。

## 9. 真实性与下一步要求

为了实现真实反演，需要灾前更精细DEM、释放区实际多边形、沿河沟道中心线/交汇点精确坐标、滑动堆积的灾前灾后DoD空间栅格、多处独立视频/地震到达时刻；另外需要网格收敛、合理水沙掺混物性和摩擦/侵蚀系数多目标反演。现有版本是可运行和可审查的基线，不是灾害过程已经正确重建的结论。
